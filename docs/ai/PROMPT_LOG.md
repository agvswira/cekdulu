# CekDulu Vibecoding Prompt Log

> **Status:** Belum dimulai. Entri pertama dibuat saat implementation Task 1 dimulai setelah setup gate dilepas secara eksplisit.

Log ini hanya mencatat interaksi AI yang memengaruhi implementasi produk. Tidak ada entri retrospektif untuk kickoff, brainstorming, desain, planning, atau setup repository.

## Aturan ringkas

- Satu entri untuk satu keputusan implementasi yang bermakna; percakapan administratif tidak dicatat.
- Prompt lengkap disimpan dalam bagian tertutup agar log mudah dipindai.
- Ringkasan hasil maksimal tiga pernyataan singkat.
- Tool/model hanya dicantumkan jika diketahui secara langsung; jika tidak, barisnya dihilangkan.
- Tidak ada kolom anggota, pemilik task, author, atau operator.
- Jangan mencatat API key, secret, data pribadi, screenshot privat, pesan mentah pengguna, atau kasus holdout.
- Log bersifat append-only. Koreksi dibuat sebagai entri baru yang merujuk entri sebelumnya.
- Entri selesai hanya setelah hasil verifikasi dan keputusan dicatat.

## Format entri

```md
## P-001 · Task 1 · 2026-08-08 14:10 WITA

**Tujuan:** Satu kalimat yang menjelaskan hasil yang ingin dicapai.

<!-- Tambahkan **Tool/model:** hanya jika nilainya diketahui secara langsung. -->

<details>
<summary>Prompt lengkap</summary>

Prompt asli tanpa perubahan.

</details>

**Hasil:** Ringkasan satu sampai tiga pernyataan singkat.

**Verifikasi:** Perintah atau pemeriksaan → hasil yang benar-benar diamati.

**Keputusan:** Diterima, direvisi, atau ditolak beserta alasan singkat.

**Artefak:** `path/file` · commit `hash` setelah commit tersedia.
```
